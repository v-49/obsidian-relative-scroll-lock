## Installation

Download relative-scroll-lock-1.0.1.zip, extract its relative-scroll-lock folder into your vault's plugin directory (normally .obsidian/plugins/), reload Obsidian, and enable Relative Scroll Lock in Community plugins settings.

The three individual plugin assets are also attached. Automatic source-code archives require building first.

## Use

Position two side-by-side Markdown panes independently, then click the status-bar control to lock scrolling without jumping. Click again to unlock, or hold Alt to temporarily adjust one pane. Supports two views of the same note and mixed reading/editing modes.

Desktop only. Obsidian 1.13.7+. No default hotkey, no network requests, and no note-body changes. Clicking Lock removes any native link between the two panes.

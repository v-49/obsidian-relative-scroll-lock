# Relative Scroll Lock 1.0.2

Now listed in [Obsidian Community Plugins](https://community.obsidian.md/plugins/relative-scroll-lock).

In Obsidian, open Settings → Community plugins → Browse, search for Relative Scroll Lock, install, and enable it. Or open the community page and select Add to Obsidian.

The English and Chinese guides now include the community installation route. Runtime behavior is unchanged from 1.0.0.

For manual installation, extract relative-scroll-lock-1.0.2.zip into the vault's plugin directory, reload Obsidian, and enable the plugin.
